      Settings & Instructions

      Instructions

      File menu: New starts an empty script. Save As... opens your system's save dialog so you can choose the folder, and reopens in that same folder next time. Save writes straight back to the file you last saved to, and only asks where if there isn't one yet. The filename is suggested from the script's title page, or from the file it was loaded from. Ctrl+S saves.

      Use Ctrl+Z and Ctrl+Y to undo and redo changes.

      With a PDF open, use the Exact View and Editable Script buttons to show either or both side by side, ⇄ to swap sides, and Match ⇔ (or Ctrl+M) to scroll the other pane to the spot you're working in.

      Click anywhere in the script to edit.

      Formatting toolbar: click a button to insert a filled-in example of that element at the cursor (the example text is pre-selected, so just start typing over it). Select script text first and the button converts every line you selected instead. Right-click a button for a menu of that element's entries already used in the script, most frequent first.

      Press Enter to create a new line. The editor will automatically maintain formatting blocks.

      To export to PDF, choose "Export as PDF" and use your browser's Print to PDF feature.
