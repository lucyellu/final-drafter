      Instructions ▼

      File menu: New starts an empty script. Save As... opens your system's save dialog so you can choose the folder, and reopens in that same folder next time. Save writes straight back to the file you last saved to, and only asks where if there isn't one yet. The filename is suggested from the script's title page, or from the file it was loaded from. Ctrl+S saves.

      Use Ctrl+Z and Ctrl+Y to undo and redo changes.

      Use the Render Mode and Edit Mode buttons to show either or both side by side, ⇄ to swap sides, and Match ⇔ (or Ctrl+M) to scroll the other pane to the spot you're working in. Render Mode shows the exact source PDF when one was imported, or a read-only paginated render of the script itself otherwise.

      Click anywhere in the script to edit.

      Formatting toolbar: click a button to insert a filled-in example of that element at the cursor (the example text is pre-selected, so just start typing over it). Select script text first and the button converts every line you selected instead. Right-click a button for a menu of that element's entries already used in the script, most frequent first.

      Variations. A passage can exist in several versions at once, like alternate pages stapled over a printed script. Press + Variation (or Ctrl+Shift+V): with nothing selected it varies the whole scene the cursor is in, and with text selected it varies exactly that passage. The passage picks up a tinted band, a rule down the margin and a card count in the gutter, with the edges of the pages behind it showing at the foot.

      Click that gutter card to fan the stack open. The deck bar pins near the top of the script pane by default, out of the way of whatever you're reading — drag it by the ⠿ grip to wherever you'd rather have it (double-click the grip to put it back). Flipping between versions (click a tab, or Alt+← / Alt+→) swaps them in place in the script, so you read each one at its real page position — but it only reads: the stack keeps its order until you say otherwise, and closing the deck (Esc) springs the passage back to the version that prints.

      ⇄ Compare opens two versions side by side with the changed words marked. Both sides are dropdowns — "Comparing" on the left is whichever version you're holding it up against, "against" on the right (marked live · editable) is the version open in the script, so picking a different one there actually flips the script to it. The ⇄ button between them swaps which side is which. Removed words are shown with a red highlight (not crossed out, so the old wording stays easy to read), added words with a green one, and take → on any line pulls it across into the version you're editing.

      Ranking. A stack is an ordered pile and the top of it is the version that stands — the one on the page, in the export, in the PDF. Drag a draft to the top of the list, in the Navigator or on the deck tabs, and it becomes that version immediately; ↑ Move to top does the same thing for whichever one you're reading. The star marks the top.

      Splitting a version out. Sometimes a "variation" turns out to be its own scene rather than a replacement for the one it was riffing on. Flip to it and press ⏎ Insert as scene: it leaves the stack, lands in the script as ordinary text right after the run it was compared against, and prints and exports like any other scene from then on. The stack stays behind with whatever versions are left; if only one remains, the stack dissolves and that one becomes plain script too.

      Numbering. Scenes are numbered down the script — S001, S002 — and every variation carries its own number, so S004.V002 names one specific piece of writing. Variation numbers are handed out once, when the variation is created, and never change: re-ranking a stack moves the star, not the numbers, so S004.V002 still means the same pages next week. That makes the label safe to quote in a note or an email. (Scene numbers do follow the script, so they shift if you reorder scenes.)

      The Navigator numbers every scene and nests that scene's drafts beneath it, shut by default — the count on the right says how many are in there, and clicking it opens the list. Has variations narrows the list to just the scenes that carry any. Only the top-ranked draft is ever exported, printed or written out as the script; the rest ride along in the .json.

      Scripts that mark their alternates by hand, with lines like * ALT DRAFT -- "THE SCULLERY EXCHANGE" *, can be converted in one step: File ▸ Fold Alternates into Stacks… lifts each one out of the appendix and staples it onto the scene it rewrites.

      Press Enter to create a new line. The editor will automatically maintain formatting blocks.

      To export to PDF, choose "Export as PDF" and use your browser's Print to PDF feature.
